1. 什么是智能体
智能体是能够：

￼
感知环境 → 分析决策 → 采取行动 → 达成目标
四个基本要素：
• 环境（Environment）：智能体所在的外部世界。
• 传感器（Sensors）：获取用户输入、API 数据、设备状态等信息。
• 执行器（Actuators）：调用工具、API、代码或物理设备执行动作。
• 目标与自主性（Goal & Autonomy）：根据当前信息自主决定下一步行动。
LLM 智能体中：

￼
用户输入和工具结果 = 感知
LLM = 决策核心
函数、API、搜索工具 = 执行器
智能体和普通程序的区别在于：普通程序通常按照固定流程执行，智能体可以根据当前环境和行动结果动态调整行为。
2. 传统智能体的类型
传统智能体按照决策能力逐步发展：
1. 简单反射智能体
通过固定的“条件—动作”规则工作。
添加到对话
￼
如果温度高于设定值 → 打开空调
2. 基于模型的反射智能体
拥有内部状态或世界模型，可以记住无法直接观察的信息。
3. 基于目标的智能体
根据目标规划行动，例如导航系统规划到达目的地的路线。
4. 基于效用的智能体
在多个目标之间权衡，例如同时考虑时间、费用和舒适度。
5. 学习型智能体
根据历史行动结果不断调整策略，强化学习是典型实现方式。

4. 智能体的分类方式

按决策时间分类

• 规划式智能体：行动前进行较完整的推理和规划。
• 混合式智能体：同时具备快速响应和长期规划能力。

LLM 智能体的环境通常具有这些特点：
• 部分可观察：智能体无法一次获得全部信息；

7. Thought-Action-Observation
典型格式：
添加到对话
￼

Action: get_weather(city="北京")
Observation: 北京今天晴天，气温26℃。
其中：
• Thought：模型对当前任务的判断；
• Action：模型决定调用的工具和参数；
• Observation：工具执行后返回的结果。
实际执行关系是：
添加到对话
￼
LLM 输出 Action
    ↓
Python 解析 Action
    ↓
Python 调用对应工具
    ↓
得到工具结果
    ↓
把结果放入下一轮提示词
LLM 不会直接执行 Python 函数，程序才是真正的执行者。

只规定目标，让智能体自主决定步骤：

• 能处理模糊目标；
