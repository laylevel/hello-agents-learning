1.2 符号主义实践为什么挑战“充分性”
符号主义最大的问题不是“不会推理”，而是：
符号系统能够进行推理，但不代表仅靠符号系统就足以解决现实世界中的一般智能问题。
主要问题：
• 知识获取瓶颈：现实世界知识太多，无法全部人工编码。
• 脆弱性：规则通常只覆盖设计时考虑的情况，遇到新情况容易失效。
• 组合复杂度高：规则越来越多后，规则之间会互相影响，维护困难。
• 常识问题：大量人类默认知道的常识很难形式化。
• 符号落地问题（symbol grounding）：系统内部的“符号”如何真正对应现实世界中的对象、感知和经验，是长期争论的问题。
因此，实践表明：
符号操作本身可能是智能的重要组成部分，但“仅靠符号系统就足以实现一般智能”这一强论断受到了挑战。

1.3 大语言模型是否符合PSSH？
不能简单说“符合”或“不符合”。
从底层实现看，大语言模型最终仍然运行在计算机这一物理系统上，其内部也存在大量离散表示和计算过程。

所以我的理解是：

2. 专家系统 MYCIN
2.1 为什么MYCIN没有大规模进入临床？
除了知识获取瓶颈和脆弱性，还存在：
技术层面
• 医疗数据复杂且不完整
• 病人的真实情况经常超出规则覆盖范围
• 医疗知识不断更新，规则库需要持续维护
• 很难处理大量非结构化信息，如影像、病历文本等
伦理层面
• 错误诊断可能直接影响患者安全
• 系统给出错误建议时，责任如何认定？
• AI建议与医生判断冲突时应该听谁的？
法律层面
• 医疗决策涉及医疗责任
• 系统错误导致损害后，需要明确开发者、医院、医生之间的责任
• 医疗软件还涉及隐私和数据安全问题
用户接受度
• 医生可能不愿意重复录入大量患者信息
• 医生可能不完全信任“机器专家”
• 如果系统不能很好地解释结论，临床接受度会下降
MYCIN实际面临的一个问题就是需要医生录入大量病人信息，这本身就影响了临床使用。

3.4 为什么会出现“组合爆炸”？
假设系统有：
• N 个关键词
• 每个关键词有 K 种可能情况
随着关键词和规则增加，可能的组合数量会快速增长。
简单理解：
复制
1个因素 → K种组合
2个因素 → K²种组合
3个因素 → K³种组合
...
N个因素 → K^N种组合
例如：
复制
10个因素
每个因素5种情况

组合数 = 5^10 = 9,765,625
实际规则系统不一定严格等于 K^N，但它可以说明一个核心问题：
规则之间一旦发生组合，复杂度可能呈指数级增长。
所以规则系统容易出现：
复制
规则越来越多
→ 规则之间相互冲突
→ 测试数量增加
→ 修改一条规则影响其他规则
→ 维护成本快速增加

4. “心智社会”与Multi-Agent
4.1 GRASP失效会发生什么？
如果积木塔系统中的GRASP智能体负责某项关键能力，那么它失效后：
• 如果其他智能体具备替代能力，系统可能继续运行，但性能下降。
• 如果GRASP承担不可替代的功能，那么相关任务会直接失败。
所以去中心化系统的特点是：
复制
一个Agent失效
↓
不一定导致整个系统瘫痪
优势
• 模块之间相对独立
• 可以分工
• 容易扩展
• 某个模块故障时可能局部降级
劣势
• Agent之间需要通信
• 协作本身会增加复杂度
• 可能产生冲突
• 多Agent协调成本高
• 某些关键节点失效仍可能造成系统故障
